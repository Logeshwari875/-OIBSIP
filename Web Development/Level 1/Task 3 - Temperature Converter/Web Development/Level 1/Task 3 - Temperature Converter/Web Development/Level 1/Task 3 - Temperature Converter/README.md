Temperature Converter

About the Project

A simple and responsive Temperature Converter website developed using HTML, CSS, and JavaScript.

Features

- Convert temperature between Celsius and Fahrenheit.
- User-friendly interface.
- Input validation.
- Displays the converted temperature.
- Responsive design.

Technologies Used

- HTML5
- CSS3
- JavaScript

How to Use

1. Enter a temperature value.
2. Select the input temperature unit.
3. Click the Convert button.
4. View the converted temperature.
